# grade-11-advanced-maths-section-1
Section 1 (*Sets and Binomial Expansions*) of *Additional Mathematics for Senior High
Schools, Year 2* (Ministry of Education / Mathematics Association of Ghana, 2025).

## Layout

- `pretext/` — the PreTeXt version of Section 1, built and deployed by the workflows in
  `.github/`; STACK questions embedded in it live under `pretext/assets/stack/`.
- `latex/` — LaTeX transcription of the book: `book.tex` (whole book), `sectionNN/` (one
  folder per book Section, each building on its own), `tools/` (PDF-to-draft extractor,
  figure cropper).  Section 1's folder was `section1-latex/` until 2026-09-04.  See
  `latex/README.md`.
